# Технический пилот: исходники и проверочные материалы

В этой папке находятся программный код, конфигурации, исходные результаты и проверки технического пилота по влиянию ШИМ светодиодного светофора и смаза движения на машинное зрение. Текст научной статьи хранится отдельно и в репозиторий не включён.

**Статус:** проверено 20 настроечных дорожных фотографий; независимая проверка критерия выбора экспозиции и обучение логистических моделей ещё не проводились. Исходный контроль по естественным объектам не достиг заданных абсолютных порогов качества.

## Состав материалов

- `pilot/code/` — генераторы четырёх вариантов, скрипты для GT, анализатор результатов и проверки сходимости.
- `pilot/reports/config.json` — параметры пилота; `pilot/reports/source_manifest.json` — имена 20 исходных кадров, SHA-256 и сведения о вставленных светофорах.
- `pilot/reports/source_hash_validation.json` — проверка SHA-256 исходных файлов и весов YOLO: `PASS`, 20 из 20 кадров, веса совпали.
- `pilot/reports/predictions_with_sizegroups.json` — исходные численные значения confidence и размерные группы предсказанных рамок.
- `pilot/results/` — четыре фиксированных режима: полные `predictions.json`, `report.json`, сводки `summary.csv`/`summary.json` и примеры изображений `clean`/`pwm`/`motion`/`combined`.
- `pilot/gt_midpoint_export/gt_midpoint.json` — экспорт GT на середине экспозиции для 20 сцен × 4 режимов × 4 воздействий (320 записей). В каждой записи отделены естественные объекты BDD100K от крупного вставленного светофора, сохранены рамки t/2, размерные группы, видимость и статус геометрической оценки. `gt_consistency.json`: 960 проверок согласованности.
- `pilot/gt_midpoint_export/images/` — изображения с GT на t/2 для примеров каждого режима.
- `pilot/multiscene_convergence/` — пять контрастных сцен, по три сочетания параметров, 45 сравнений шагов 16→32→64→128, включая 15 сравнений 64→128. Два сравнения последней пары изменили счётчики обнаружения YOLO: поэтому общий статус `INCOMPLETE_OR_FAILED`.
- `pilot/convergence_refinement/` — уточняющий запуск только двух неустойчивых случаев, уровни 128/256/512; на последнем переходе 256→512 нарушений нет (`FOLLOW_UP_CONVERGED_ON_FAILED_CASES`). Первичный статус остаётся неизменным.
- `pilot/reports/verification_320.json` — аудит 320 записей: `PASS`, 321 проверка.
- `protocol/` — исполняемый пример формального правила с решениями A/R/U, статусами S/F/Q, консервативной верхней оценкой ошибочных разрешений, пустыми знаменателями и примером нулевых ошибок.

## Проверка таблиц 2–3 и 320 записей

Установите зависимости проекта по корневому `requirements.txt`. Для проверки уже сохранённых результатов BDD100K и YOLO не требуются.

Из директории `docs/vision_exposure` выполните:

```bash
python pilot/code/rebuild_result_zip.py --data pilot/results --out led_phase20_results.zip
python pilot/code/verify_led_phase20.py --zip led_phase20_results.zip --generator pilot/code/run_led_control_pilot.py --out audit_rerun.json
python protocol/criterion_example.py --config protocol/criterion_config.json --out protocol/criterion_example_report.json
```

Ожидается `PASS`: 20 сцен, 4 режима, 320 записей, 321 проверка. Анализатор сверяет сохранённые счётчики и манифест, а не независимым способом проверяет физику камеры.

## Проверка GT и многосценовой сходимости

Эти результаты **уже получены** и находятся в `pilot/gt_midpoint_export/` и `pilot/multiscene_convergence/`. Переходить к заключению о сходимости по ним пока нельзя: в двух случаях YOLO изменил число обнаружений между 64 и 128 временными шагами. Максимальные значения на этой паре: средняя разность линейной яркости `4.78508991363924e-05`, абсолютное изменение контраста `6.994911978686069e-05`; геометрические GT-рамки на t/2 совпали.

Дополнительная проверка **двух не прошедших случаев** выполнена на уровнях 128, 256 и 512 шагов; сделаны четыре сравнения соседних уровней. На последнем переходе 256→512 нарушений критериев нет (`last_pair_failures: []`), статус отдельного отчёта — `FOLLOW_UP_CONVERGED_ON_FAILED_CASES`. Результат находится в `pilot/convergence_refinement/report.json`; данные сравнений и исходные предсказания сохраняются в той же папке. Для независимого повторного запуска нужны локальные исходные фотографии и `yolo11s.pt`:

```bash
python pilot/code/run_convergence_refinement.py --project-root /path/to/local_project_with_bdd_and_yolo --base-report pilot/multiscene_convergence/report.json --output pilot/convergence_refinement
```

Исходный статус `INCOMPLETE_OR_FAILED` **не меняется**: в нём зафиксированы два неустойчивых сравнения 64→128. Уточнение показывает численную сходимость на паре 256→512 только для этих двух случаев, а не гарантирует 128 шагов для всех комбинаций. Оно также не подтверждает пригодность чистого контроля или основную гипотезу.

## Ограничения

Исходные JPEG BDD100K и веса YOLO не входят в репозиторий. Для повторного синтеза на всех сценах их необходимо получить отдельно и проверить SHA-256 по манифесту. Вставленный крупный светофор не является естественным объектом BDD100K; его цветовой результат нельзя переносить на малые реальные светофоры. Двумерный синтез на основе JPEG с неизвестной исходной экспозицией служит технической проверкой, а не физически точной моделью сенсора. Рабочий чистый контроль ещё не прошёл исследовательские минимумы, логистический критерий не обучен и на независимой выборке не проверен.
